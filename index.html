QUESTION 01

var vs let vs const

Definition: var, let, and const are JavaScript keywords used to declare variables, but they differ in scope, reassignment, redeclaration, and hoisting.

Example

var name = "Ali";
name = "Ahmed";

let age = 20;
age = 21;

const country = "Pakistan";

console.log(name);
console.log(age);
console.log(country);

Key Differences

Feature var let const
Scope Function Block Block
Reassignment Yes Yes No
Redeclaration Yes No No
QUESTION 02

== vs ===

Definition: == compares values after type conversion, while === compares both value and data type without type conversion.

Example

console.log(5 == "5");
// true

console.log(5 === "5");
// false

QUESTION 03

Closures

Definition: A closure is a function that remembers and can access variables from its outer function even after the outer function has finished executing.

Example

function counter() {

    let count = 0;

    return function () {
        count++;
        return count;
    };
}

const myCounter = counter();

console.log(myCounter());
console.log(myCounter());
console.log(myCounter());

QUESTION 05

Promise and async/await

Definition: A Promise represents the future result of an asynchronous operation, while async/await provides cleaner syntax for working with Promises.

Promise Example

const myPromise = new Promise((resolve, reject) => {

    const success = true;

    if (success) {
        resolve("Task completed successfully");
    } else {
        reject("Task failed");
    }

});

myPromise
    .then(result => console.log(result))
    .catch(error => console.log(error));

async/await Example

async function getData() {

}
QUESTION 06

Array Methods

Definition: map(), filter(), reduce(), and forEach() are JavaScript array methods used to process array elements.

map()

Creates a new array by transforming every element. 

[1, 2, 3].map(x => x * 2);

filter()

Creates a new array containing matching elements. 

[1, 2, 3, 4]
.filter(x => x > 2);

reduce()

Combines array elements into one value. 

[1, 2, 3, 4]
.reduce((a, b) => a + b, 0);

forEach()

Executes a function for every element. 

[1, 2, 3]
.forEach(x => console.log(x));

QUESTION 09

Arrow Function this

Definition: Arrow functions do not have their own this; they inherit this from the surrounding lexical scope.

Incorrect Example

const person = {

    name: "Khadija",

    getName: () => {
        return this.name;
    }

};

The arrow function does not create its own this, so it does not refer to the person object.

Correct Example

const person = {

    name: "Khadija",

    getName: function () {
        return this.name;
    }

};

console.log(person.getName());
